# Open Auto Trade roadmap

Open Auto Trade is a free, open-source vehicle discovery, import planning and ownership information project for Africa. This roadmap distinguishes what exists from what still requires evidence or development.

## Released

- Responsive public website and mobile navigation
- Links to non-auction international dealer/exporter websites
- Links to independent freight carriers and freight-forwarding companies
- Destination selector covering 54 African countries, with country-specific authority links for selected countries and clear fallback guidance elsewhere
- Manual landed-cost planner and two-vehicle comparison; neither provides binding quotes or official tax calculations
- Import journey checklist and inspection, payment and customs resource links
- Public NHTSA VIN and model lookup endpoints, subject to NHTSA coverage
- GitHub contribution and correction issue templates
- Published provider verification standards and source notes

## Next priorities

1. **Coverage accuracy:** Verify official customs resources and import restrictions country by country, with dates and citations. Avoid universal eligibility claims.
2. **Directory quality:** Review official provider URLs, document supported regions and vehicle-specific limitations, and fix broken or outdated links.
3. **Ownership resources:** Add well-sourced spare-parts catalogues, OEM compatibility guidance, independent workshops and maintenance information without implying endorsement.
4. **Usability:** Test mobile and low-bandwidth navigation, accessibility and readability; fix reported issues.
5. **Community maintenance:** Review issue submissions, record evidence and update verification dates.

## Future possibilities, not currently offered

- Authorized, licensed dealer inventory feeds where agreements and display rights allow
- More detailed import calculators based on independently verified official sources
- Optional saved searches with privacy-preserving accounts
- Additional languages and regional localization
- Partner integrations only when contracts, eligibility and permissions are established

## Verification and product boundaries

A directory link is **not** a live integration or an approved partnership. Never describe a route, appointment, quote, customs calculation or dealer stock as confirmed without suitable current evidence. See [DIRECTORY_VERIFICATION.md](DIRECTORY_VERIFICATION.md).

No MaxBid proprietary assessments, internal bid ceilings, private supplier contacts, credentials or user data may be copied into this repository.
