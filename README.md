# Open Auto Trade

Free, open-source automotive access and import-planning tools for Africa.

Founded by Elvis Kamau. Initially stewarded by Sahara Trade Hub LLC.

## Current release
- Responsive public landing page
- Manual landed-cost planning calculator in USD, with African destination selector
- Clear disclosures: tax estimates are user-entered, not official customs calculations
- No citizenship gate or personal-document collection

## Not yet available
- Authorized real-time external vehicle feeds
- Official country-specific customs calculation
- Verified suppliers, spare-parts and mechanics directory
- Payment or shipment booking

## Local development
Open `index.html` in a browser. No build tools or secrets required.

## Contributing
Open an issue before substantial changes. Never commit API keys, user data, proprietary vehicle feeds, or content without redistribution rights. Contributions are reviewed by project maintainers.
