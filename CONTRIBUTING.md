# Contributing to Open Auto Trade

We welcome contributors from every country. No citizenship or passport requirement.

## Ways to help
- Add reviewed, dated links to official vehicle import regulations for African destinations.
- Improve accessibility, localization and low-bandwidth performance.
- Propose vehicle data providers with documented API access and redistribution rights.
- Contribute maintenance guidance with cited references.

## Safety and data integrity
- Never upload passports, identity documents, user records, credentials or secret keys.
- Never scrape or redistribute listings without permission.
- Clearly label manually entered estimates and distinguish them from official taxes or live prices.
- Do not publish supplier endorsements without a verifiable review process.
- Submit changes as pull requests and include testing steps.

## Community
Be respectful. Harassment and discrimination are not welcome.
