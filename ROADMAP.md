# Open Auto Trade roadmap

## Released
- Public, mobile-friendly website
- Editable landed-cost planning calculator (not official tax computation)
- Two-vehicle manual landed-cost comparison
- Vehicle import verification checklist
- Public MIT source code

## Next — no live integration claims until verified
1. Country regulations: source, publication date, official URL, update cadence and independent review for each country.
2. Authorized inventory integration: signed provider agreement/API terms, working requests, currency and timestamp normalization, deduplication, permitted public display.
3. Shipping estimates: validated routes, destination port, freight and insurance assumptions; never imply binding quotes.
4. Parts and maintenance: OEM compatibility evidence, mechanic/provider verification, complaints process.
5. Accessible multilingual and low-bandwidth experiences.
6. Privacy-preserving optional accounts for saved searches; no citizenship-based browsing gate.

## Verification gates
A provider is LIVE only after its authorization, successful external response, valid mappings, display rights, and monitored freshness are verified. Until then, show 'Not connected' or 'Under investigation'.

## Product separation
No MaxBid proprietary assessments, internal bid ceilings, private supplier contacts, credentials or user data may be copied into this repository.
